# DSU
diberikan beberapa elemen dan 2 set elemen yang berbeda, dsu bisa menggabungkan 2 set dan mencari suatu elemen ada di set mana
- make_set(v) buat set baru berisi elemen v
- union_state(a,b) merge 2 set, set pertama dimana lokasi a berada, set kedua dimana elemen b berada
- find_set(v) ngembaliin head dari set tempat elemen v berada

semua operasi : `O(N)`
